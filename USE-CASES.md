# Use-case map: the fully operational production system

Day One Great on giscus/GitHub sign-in, with JEVs wrapped around the database. Every role below must work end to end in production. Written Oct 24, 2026 from Aaron's instructions and the three expert plans (AI, scalability, CSO). This file is the checklist: each row is done only when its "Done when" passes live. Aaron's only action is merging PRs.

| # | Use case | Role in production | Works today | Missing code | Done when |
