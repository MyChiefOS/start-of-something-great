WhenWhoAction

Sign-ins that failed

Every wrong key file and PIN is counted against the key it was tried with. The 3rd wrong key file for a username pauses key-file sign-in for 10 minutes, the 5th wrong key file or PIN alerts you, the 10th cancels it, and a sign-in after wrong tries alerts you; the member is told each time. Since 053, 3 failed sign-ins in 15 minutes also lock the account, every way in, for 15 minutes; you can release a lock early. These are the times a count reached a limit, newest first.
